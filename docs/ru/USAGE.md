# Руководство пользователя

**Руководство** · [Разработка](DEVELOPMENT.md) · [Протокол](PROTOCOL.md)

## Запуск

Приложение работает на Windows 10/11. Для запуска нужны WebView2 и
[Npcap](https://npcap.com/) для живого захвата. Запустите готовый файл `aurion.exe`.
Сборка из исходников описана в [руководстве разработчика](DEVELOPMENT.md).

### Первый запуск внутри игры

Запуск Aurion до входа в мир позволяет получить полные начальные данные персонажа.
При запуске внутри игровой сессии Aurion может определить класс по наблюдаемым собственным
классовым умениям и загрузить подходящие HUD без повторного входа. Общие умения не определяют
класс. Импорт профиля загружает только его оформление и правила.

Редактор сообщает, если данные персонажа неполные. Имя, HP/MP и полный список умений требуют
соответствующих сообщений сервера: приложение не подставляет данные других персонажей.
Если эти данные не появляются, оставьте Aurion открытым, вернитесь к выбору персонажа
и войдите в мир снова.
После успешного подключения Aurion сохраняет снимок для следующих перезапусков в той же игровой сессии.

### Обновления

Aurion проверяет последний публичный релиз GitHub при запуске и раз в четыре часа.
Новая стабильная версия отображается в редакторе и настройках, а на тулбаре появляется индикатор.
В разделе **Настройки → Обновления** можно увидеть установленную версию, проверить обновления
вручную и открыть страницу релиза. Новый архив нужно скачать и распаковать самостоятельно:
Aurion не заменяет исполняемый файл автоматически. Отсутствие сети не блокирует HUD и редактор.

### Npcap и права доступа

Установите [Npcap](https://npcap.com/#download). Aurion загружает Npcap напрямую,
поэтому опция «Install Npcap in WinPcap API-compatible Mode» не обязательна.
Если при установке вы ограничили захват только администраторами,
запускайте Aurion от имени администратора. Подробности опций — в
[руководстве Npcap](https://npcap.com/guide/npcap-users-guide.html).

Если AION 2 запущена от имени администратора, запускайте Aurion на том же уровне
прав, чтобы управление видимостью HUD через Alt работало при фокусе игры.

### Слои

По умолчанию слои встроены справа. В меню **⋯** заголовка «Слои» можно выбрать
**Справа**, **Слева** или **Отдельное окно**. Ширина встроенной панели меняется
перетаскиванием разделителя; отдельную панель можно перемещать за заголовок и менять
её размер за края. Расположение, ширина, координаты и размер отдельной панели
запоминаются локально. Кнопка слоёв в боковой панели редактора скрывает и открывает их.

## Игровые данные и видимость

Aurion читает входящий игровой трафик через Npcap. Иконки умений и эффектов скачиваются
с `assets.playnccdn.com` и сохраняются в локальном кеше. Без подключения уже скачанные иконки доступны.

В обычной игре HUD и окна DPS/HPS следуют за фокусом игры и скрываются поверх распознанных
игровых окон. Само удержание Alt для показа курсора HUD не скрывает. У редактора отдельная видимость.

После перезапуска Aurion при открытой игре данные сеанса могут восстановить персонажа
и ресурсы. Восстановленные значения остаются приблизительными до свежего обновления из игры;
часть сведений может отсутствовать, пока игра не пришлёт их снова.

## Известные ограничения

- Сброс босса без события смерти может оставить бой открытым и объединить следующую попытку
  с предыдущей. Это возможно и после вайпа, если участник группы или его здоровье неизвестны.
  Элементы HUD с условием «в бою» могут оставаться активными до подтверждённого конца или смены карты.
- Поддержка группы экспериментальная. После смены инстанса могут отсутствовать участники или их статистика.
- Отмена зарядки пока не распознаётся; полоса может идти до конца длительности из каталога.
- Игровые окна определяются по курсору и Alt. Если открыть окно при зажатом Alt,
  HUD может остаться видимым поверх него.

## Данные пользователя

Папка данных — `%APPDATA%/aurion` (или `AURION_DATA_DIRECTORY`).

```text
preferences.json          настройки приложения
combat-journal.json       окна и оформление журнала
combat-reports.json       история боёв (по умолчанию 50, максимум 100)
game-session.json         сохранённые персонаж, ресурсы, книга умений и NPC
world-boss-cache.json     наблюдения боссов текущего процесса игры, отдельно по серверам
icon-cache/               иконки, скачанные с assets.playnccdn.com
aurion.log                ошибки загрузки иконок
profiles/
  workspace.json          версия формата, ревизия, порядок профилей
  <Профиль>/
    interface.json        элементы, формулы, сведения, масштаб HUD
    locales/<язык>.json   авторские переводы: исходная строка → перевод
```
