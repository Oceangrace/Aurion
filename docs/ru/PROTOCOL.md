# Протокол AION 2

[Руководство](USAGE.md) · [Разработка](DEVELOPMENT.md) · **Протокол**

Aurion читает входящий трафик игры через Npcap или воспроизводит запись PCAP.
Текущий парсер использует данные сборки клиента 32.

## Ограничения

- Отсутствующие значения остаются неизвестными, а не заменяются нулём.
- Разрыв захвата и позднее подключение могут привести к неполным данным боя.
- Цель цели определяется по кастам и применениям умений; настоящее агро недоступно.
- Окончание отката не гарантирует доступность умения: ещё нужны мана, дистанция и отсутствие контроля.
- Для воспроизведения подходит classic PCAP little-endian. PCAPNG не поддерживается.
